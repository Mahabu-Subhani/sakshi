SAKSHI

साक्षी · Hindi for witness · offline · CPU only · MIT licence

It doesn’t ask whether a document looks fake. It asks what the documents would have to say for every rule to hold, and shows the evidence. It never says “fraud”: a human decides.

Run it yourself

With Docker, nothing else to install. The review console opens at http://localhost:8501; pick a demo case and press Investigate.

git clone https://github.com/Mahabu-Subhani/sakshi.git
cd sakshi
docker build -t sakshi .
docker run --rm -p 8501:8501 sakshi

For a loan-origination system: python -m sakshi serve accepts cases at POST /v1/cases (bearer token) and runs several side by side; python -m sakshi batch does the same for a folder of applications.

Without Docker, see the quick start. Results, limitations and the technical design are in the README and docs.
